핵심 요구사항 분석

  • 3개 이종 소스 통합 — ERP(수입검사리스트·합부현황·품목·S오더), QMS(부적합등록·부적합정보·협력업체부적합·실패비용·F오더), 네트워크 공유 엑셀(ITP 정합성)을 Power Query 단일 파이프라인으로 추출·정제·통합
  • 코드 체계 통일 및 중복 제거 — ERP와 QMS의 상이한 코드 체계를 매핑 테이블로 통일하고, S오더↔F오더 연결로 중복 집계를 제거하여 원본 대비 집계 오차 0 확보
  • 14개 KPI 측정값(DAX) — 전체검사건수, 부적합건수, 부적합률, 공정부적합건수, 공정부적합률, NCR 발행·접수, 검사 건수 추이, 부적합 유형·원인 현황, ITP 정합율(누적·추이), TOP5 부적합 공급업체, 장치별 부적합 건수
  • 전월 대비 · 전년 동기 비교 — 화면 구성 초안의 KPI 카드에 전월 실적값과 증감률(▲▼%)이 병기되어 있어, KPI별 기준값·전월값·전년동기값 3종 측정값 세트를 타임 인텔리전스로 구성
  • 실패비용 정량화 — QMS 실패비용 데이터를 합의된 산정·배부 기준에 따라 집계하여 기간별 금액으로 표출
  • 필터·슬라이서 — 기간·업체·장치에 더해, 화면 초안 우측 상단에 확인되는 검사구분(수입검사 등) 드롭다운 슬라이서 포함. 조건 변경 시 전체 KPI 재계산
  • 대형 모니터 상시 표출 — 다크 배경 고대비 커스텀 테마(JSON) 적용, 풀스크린 그리드 최적화로 원거리 가독성 확보
  • 무인 자동 새로고침 — 온프렘 데이터 게이트웨이로 ERP·QMS DB 및 엑셀 공유 경로를 최소 일 1회 자동 갱신, 실패 시 이전 데이터 유지 및 알림
  • 접근 권한 분리 — 게시 후 지정 인원만 열람 가능하도록 권한 설정, 미승인 사용자 접근 차단

제안 포인트

1. 「집계 오차 0」을 설계 단계부터 검수 기준으로 고정합니다

본 프로젝트의 최대 리스크는 화면 구현이 아니라 ERP와 QMS의 코드 체계 차이로 인한 집계 불일치입니다. 착수 직후 데이터 매핑 정의서(코드 매핑 · S오더↔F오더 매핑 규칙)를 먼저 확정하고, 각 마일스톤마다 원본 시스템 조회 결과와 대시보드 수치를 1:1로 대사(reconciliation)하는 검증표를 산출물로 제출합니다. 대사 결과는 검수 시 그대로 증빙으로 사용하실 수 있습니다.

2. 화면 구성 초안을 14개 구성요소 단위로 분해하여 공수에 반영했습니다

제공해 주신 화면 구성 초안을 분석한 결과, 단순 카드형이 아닌 이중 Y축 콤보 차트(검사 건수 추이), 누적 막대 + 이중축(장치별 부적합 · ITP 정합율 추이), 도넛 게이지(ITP 정합율 누적실적), 구성비(%) 열이 포함된 TOP5 테이블 등 시각화 유형이 각기 다릅니다. 또한 KPI 카드마다 전월 실적값과 증감률이 병기되어 있어, 14개 KPI에 대해 기준값·전월값·전년동기값 3종 측정값 세트가 필요합니다. 이 구조를 그대로 반영하여 DAX 5 M/D · 대시보드 구현 5.5 M/D로 산정했습니다.

3. 대형 모니터 상시 표출을 「기능」이 아닌 「설계 전제」로 다룹니다

상시 표출은 게시 후 풀스크린 버튼을 누르는 것과 다릅니다. 원거리 판독을 위한 폰트 스케일·대비비, 무인 환경에서의 자동 페이지 전환, 게이트웨이 새로고침 실패 시 화면 정지 방지, 세션 만료 대응까지 함께 설계해야 합니다. 초안의 다크 네이비 배색을 Power BI 커스텀 테마 파일(JSON)로 표준화하여 전 페이지에 일관 적용하고, 실제 표출 해상도 기준으로 그리드를 확정한 뒤 현장 검증을 거칩니다.

4. 발주처 준비 사항의 지연 리스크를 착수 첫 주에 몰아서 해소합니다

본 건은 DB 읽기 계정 · 스키마 · 엑셀 경로 권한 · 코드 정의서 · 실패비용 산정 기준 등 발주처 준비 사항에 일정이 종속됩니다. 이를 Phase 1(Day 1–6)에 집중 배치하고, 필요 항목을 체크리스트로 사전 발송하여 전산팀 협의를 1회 미팅으로 종결하는 것을 목표로 합니다. 동시에 데이터 확보 전에도 진행 가능한 데이터 모델 설계 · 테마 제작 · 시각화 프로토타입을 병행하여 대기 시간을 흡수합니다.

5. 확장(Full) 범위로의 연결을 전제로 구조를 잡습니다

공고에 정합성 자동 검증 리포트 · 품질/운영 현황 페이지 · 사용자 교육이 확장 범위로 명시되어 있고, 고도화 프로젝트 의뢰 예정임을 밝히셨습니다. 이번 단계의 데이터 모델을 페이지 추가만으로 확장 가능한 스타 스키마로 설계하고, 측정값을 재사용 가능한 단위로 분리하여 후속 고도화 시 ETL 재작업이 발생하지 않도록 합니다.

산정 근거

  • 산정 방식 — 총 34 M/D × 225,000원/M·D = 7,650,000원 (VAT 별도). 발주처 예상 금액 9,000,000원 대비 85% 수준으로 제안합니다.
  • 공수 비중 — 데이터 엔지니어링(ETL·정제·모델링) 12 M/D(35.3%)가 가장 큰 비중입니다. 본 프로젝트의 난이도는 시각화가 아니라 3개 이종 소스의 코드 통일과 중복 제거에 있다고 판단했습니다.
  • 화면 초안 반영분 — 이중 Y축 콤보 2종, 누적 막대 2종, 도넛 게이지, 구성비 포함 TOP5 테이블, 전월 증감 병기 KPI 카드 7종 등 시각화 유형이 상이하여 단순 카드 배치 대비 공수를 상향 반영했습니다.
  • 검증 공수 별도 계상 — 「원본 대비 KPI 집계 오차 없음」이 검수 기준이므로, 대사 검증을 QA 항목으로 분리하여 2.5 M/D를 명시적으로 계상했습니다.
  • 제외 항목 — Power BI 라이선스(발주처 부담), 표출용 모니터·게이트웨이 서버 등 하드웨어, ERP·QMS 시스템 자체 기능 변경은 견적에 포함하지 않았습니다.
  • 지급 조건 (제안) — 착수금 30% / 중도금 40%(M3 KPI·DAX 완료) / 잔금 30%(검수 완료). 발주처 기준에 맞춰 조정 가능합니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다.

1. 프로젝트 배경 및 목적

수입검사·부적합 데이터가 ERP(수입/완성검사) · QMS(부적합관리) · 오프라인 엑셀(ITP 정합성) 3곳에 분산되어 있어, 현황 파악을 위해 매번 수작업 취합이 필요하고 코드 체계 차이·중복 집계로 인한 오류가 발생하기 쉬운 상태입니다.

본 프로젝트의 목적은 3개 소스를 하나의 ETL 파이프라인으로 통합하여 14개 KPI와 실패비용을 자동 집계하고, 이를 특정 공간의 대형 모니터에 상시 표출(풀스크린)하여 품질 현황을 팀 전체가 실시간으로 공유하도록 하는 것입니다.

목표 지표

  • 수작업 취합 시간 제거 — 최소 일 1회 무인 자동 새로고침으로 상시 최신 상태 유지
  • 원본 대비 KPI 집계 오차 0 — 코드 통일·중복 제거 규칙을 정의서로 명문화하고 대사 검증표로 증빙
  • 재발 방지 지원 — 부적합 유형·원인·공급업체·장치별 다차원 분석 제공
  • 품질 투자 의사결정 근거 확보 — 실패비용 정량화 및 전년도 동기 대비 개선 추이 확인

3. 기능 요구사항

3.1 데이터 연동 (ETL)

  • [필수] ERP 직접 DB 조회 — 수입검사리스트, 합부현황, 품목, S오더
  • [필수] QMS 직접 DB 조회 — 부적합등록, 부적합정보, 협력업체부적합, 실패비용, F오더
  • [필수] 오프라인 엑셀 연동 — 네트워크 공유 경로의 ITP 정합성 시트, 일간 갱신 대응
  • [필수] 증분/전체 새로고침 정책 수립 — 데이터량에 따라 착수 단계에서 확정

3.2 정제 · 통합

  • [필수] 결측·형식 표준화 (날짜·수량·금액·코드 값)
  • [필수] ERP-QMS 코드 체계 통일 — 부적합 유형·원인·공급업체·장치 코드 매핑 테이블
  • [필수] 중복 제거 규칙 정의 및 적용
  • [필수] S오더(ERP) ↔ F오더(QMS) 매핑 로직
  • [필수] 스타 스키마 데이터 모델 (검사 팩트 · 부적합 팩트 + 날짜·업체·장치·유형·원인 디멘션)

3.3 KPI 및 측정 로직 (DAX)

  • [필수] 기본 KPI 7종 — ① 전체검사건수 ② 부적합건수 ③ 부적합률(%) ④ 공정부적합건수 ⑤ 공정부적합률(%) ⑥ NCR 발행 ⑦ NCR 접수
  • [필수] 분석 KPI 7종 — ⑧ 검사 건수 추이(월별) ⑨ 부적합 유형 현황 ⑩ 부적합 원인 현황 ⑪ ITP 정합율(누적실적) ⑫ TOP5 부적합 공급업체(구성비 포함) ⑬ 장치별 부적합 건수 ⑭ ITP 정합율 추이(월별)
  • [필수] 전월 대비 증감 — 화면 초안 KPI 카드의 전월 실적값·증감률(▲▼%) 표기 구현
  • [필수] 전년 동기 비교 — 14개 KPI 전체에 대한 전년 동기 측정값 세트
  • [필수] 실패비용 산출 — 합의된 집계·배부 기준에 따른 기간별 금액 집계

3.4 대시보드 화면

  • [필수] 메인 대시보드 — 화면 구성 초안의 14개 구성요소를 3단 그리드로 배치 (KPI 카드 7종 / 추이·도넛·게이지 4종 / 테이블·막대 3종)
  • [필수] 시각화 유형 — 이중 Y축 콤보(검사 건수 추이), 도넛 2종(유형·원인), 도넛 게이지(ITP 정합율 누적), 순위 테이블(TOP5, 구성비% 포함), 누적 막대 이중축 2종(장치별·ITP 추이)
  • [필수] 슬라이서 — 검사구분(화면 초안 우측 상단 드롭다운), 기간, 공급업체, 장치
  • [필수] 전년도 비교·추이 페이지 — 14개 KPI 전년 동기 수치 나란히 표시
  • [필수] 대형 모니터 풀스크린 보기 — 커스텀 테마(다크 배색) 적용, 원거리 가독성 확보
  • [선택] 페이지 자동 전환(순환 표출) — 상시 표출 운영 방식에 따라 협의

3.5 운영 · 배포

  • [필수] 온프렘 데이터 게이트웨이 설치 및 데이터 원본 등록

  • 상시 표출 방식(Power BI Service 게시 후 브라우저 풀스크린 / 온프렘 Report Server)에 따라 필요한 라이선스 종류가 달라지므로, 발주처 구매 전 요건을 정리하여 제공해 드립니다.

6. 범위 외 사항 (Out of Scope)

  • ERP·QMS 시스템 자체의 기능 변경 및 커스터마이징
  • 정합성 자동 검증 리포트 (확장 범위 — 별도 협의)
